# GlassDock documentation

GlassDock is a Python/GTK 3 dock for Wayland. It uses gtk-layer-shell for placement and Sway IPC for running-window information.

## Quick install

```bash
curl -fsSL https://raw.githubusercontent.com/Mandrusian/GlassDock/master/installer.sh | bash
```

The installer is interactive in a terminal. It can install, update, or uninstall GlassDock and GlassIcon Studio.
