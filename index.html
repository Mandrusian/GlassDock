02 / Everyday essentials

A dock that stays out of the way.

Dock behavior, launcher handling, and Sway integration.

01

Apps and windows

Pin launchers, group windows by app, drag to reorder items, and see running applications through Sway IPC.

02

Position and behavior

Set the edge, alignment, margins, exclusive zone, per-monitor overrides, auto-hide, and fullscreen behavior.

03

Settings that make sense

Adjust size, spacing, opacity, borders, shadows, animation, indicators, launchers, and other options in the GTK settings app.

04

Control your way

Use app context menus or wire dock commands into your compositor keybindings. Optional login autostart is included.

Quick reference

Useful commands.

$ glassdock &
# Open the settings window
$ glassdock-settings
# Check status, refresh, or toggle visibility
$ glassdock-ctl status
$ glassdock-ctl reload
$ glassdock-ctl toggle

03 / Companion app

GlassIcon Studio.

GlassIcon Studio changes icon themes, app icons, and file-manager icons for your user.

It uses Python and GTK 3. No background service or root access is needed for icon changes. The installer and uninstaller keep your settings and backups.

04 / Make it yours

An appearance that fits.

Appearance presets include Smoky Glass, Dark, Light, macOS-inspired, Liquid Glass-inspired, Purple/Pink, and Custom. You can change colors, opacity, borders, shadows, size, and animation in Settings.

05 / Requirements

Built for the Linux desktop.

GlassDock is written in Python with GTK 3 and gtk-layer-shell.

What you need

Requires Wayland with wlr-layer-shell, Python 3.9+, GTK 3, PyGObject, Pycairo, and gtk-layer-shell. Sway or SwayFX is recommended for window tracking.

Transparency depends on compositor support. Background blur needs SwayFX with layer_effects.

Manual installation

$ git clone https://github.com/Mandrusian/GlassDock.git
$ cd GlassDock
$ ./scripts/install-deps.sh
$ ./install.sh
$ ./scripts/run-tests.sh
