02 / Everyday essentials

A dock that stays out of the way.

Useful controls without turning your desktop into another environment to manage.

01

Apps and windows

Pin launchers, group windows by app, drag to reorder items, and see running applications through Sway IPC.

02

Position and behavior

Set the edge, alignment, margins, exclusive zone, per-monitor overrides, auto-hide, and fullscreen behavior.

03

Settings that make sense

Adjust size, spacing, opacity, borders, shadows, animation, indicators, launchers, and other options in the GTK settings app.

04

Control your way

Use app context menus or wire dock commands into your compositor keybindings. Optional login autostart is included.

Quick reference

Useful commands.

$ glassdock &
# Open the settings window
$ glassdock-settings
# Check status, refresh, or toggle visibility
$ glassdock-ctl status
$ glassdock-ctl reload
$ glassdock-ctl toggle

03 / Companion app

GlassIcon Studio.

Keep the rest of your desktop consistent. GlassIcon Studio manages installed icon themes, per-application launcher icons, and user-level folder, Home, Trash, drive, and file-type icons.

Built with Python and GTK 3, GlassIcon works well with Thunar and lightweight window-manager setups. Icon changes run as your user, without a background daemon or root access. Its own installer and uninstaller preserve your icon settings and backups.

04 / Make it yours

An appearance that fits.

GlassDock includes Smoky Glass, Dark, Light, macOS-inspired, Liquid Glass-inspired, Purple/Pink, and Custom appearance options. The Settings app lets you tune color, gradients, opacity, borders, shadows, corner radius, sizing, and animation, so you can keep the dock quiet or give it more contrast without changing the rest of your desktop.

05 / Requirements

Built for the Linux desktop.

GlassDock is a small Python and GTK application, designed around native Wayland surfaces.

What you need

A Wayland session with wlr-layer-shell, Python 3.9 or newer, GTK 3, PyGObject, Pycairo, and gtk-layer-shell. Sway or SwayFX is recommended for window and running-app integration.

The dock can be translucent on supported compositors. Desktop background blur specifically requires SwayFX with its layer_effects support.

Manual installation

$ git clone https://github.com/Mandrusian/GlassDock.git
$ cd GlassDock
$ ./scripts/install-deps.sh
$ ./install.sh
$ ./scripts/run-tests.sh
