A few useful commands
$ glassdock &
# Open the visual settings app
$ glassdock-settings

# Check the running dock
$ glassdock-ctl status

# Refresh or toggle visibility
$ glassdock-ctl reload
$ glassdock-ctl toggle
Make it part of your Sway setup
# Toggle the dock
bindsym $mod+Ctrl+d exec glassdock-ctl toggle

# Focus the first dock item
bindsym $mod+Ctrl+1 exec glassdock-ctl launch 1

A transparent note on blur: GlassDock can be translucent on supported compositors. Real background blur specifically requires SwayFX and its layer_effects support.

Under the glass.

A small, transparent project built on familiar Linux desktop technologies.

Prefer a manual install? Clone the repository and use the bundled scripts:

From source
$ git clone https://github.com/Mandrusian/GlassDock.git
$ cd GlassDock
$ ./scripts/install-deps.sh
$ ./install.sh
$ ./scripts/run-tests.sh

Built for: Wayland sessions with wlr-layer-shell, Python 3.9+, GTK 3, PyGObject, Pycairo, and gtk-layer-shell. Sway or SwayFX is recommended for window and running-app integration.

Made to be yours: settings live in ~/.config/glassdock/config.json. The uninstaller keeps them unless you explicitly choose to remove them.

One compositor caveat: rendering, layer placement, and blur can vary by environment, so validate these in your own Wayland session.
