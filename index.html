GlassDock

A little dock.
A smoother desktop.

A floating, customizable dock for Wayland. Pin your apps, follow your workflow, and tune every detail without replacing your desktop environment.

Wayland-native Sway + SwayFX GTK 3 MIT licensed

🚀 Install GlassDock

curl -fsSL https://raw.githubusercontent.com/Mandrusian/GlassDock/master/installer.sh | bash

Paste into a terminal to open the guided setup. It offers Install / Upgrade, Uninstall, and Exit. Review the installer source before running it.

🛠️ Your desktop, your dock

A focused launcher with thoughtful controls, from first launch to per-monitor details.

GlassDock brings a macOS-inspired dock feel to Linux without pretending to be a whole desktop shell. It runs as a Wayland layer-shell surface and is designed around Sway and SwayFX.

📌

Your favorite apps, close by

Pin launchers, group windows by app, and see running-app indicators through Sway IPC.

✨

Fluid by design

Hover magnification, smooth animations, launch bounce, app labels, and drag-to-reorder launchers.

⚙️

Make it yours

Use the settings app to tune color, opacity, borders, shadows, sizing, position, behavior, and monitor overrides.

glassdock · terminal
$ glassdock &
$ glassdock-settings

# Check status at any time
$ glassdock-ctl status

# Reload, toggle, or quit
$ glassdock-ctl reload
$ glassdock-ctl toggle
$ glassdock-ctl quit
Sway keybindings
# Toggle the dock
bindsym $mod+Ctrl+d exec glassdock-ctl toggle

# Activate the first dock item
bindsym $mod+Ctrl+1 exec glassdock-ctl launch 1

Good to know: the dock can be translucent on supported compositors. Real background blur specifically requires SwayFX with its `layer_effects` support.

📦 Up and running in minutes

The guided installer handles the everyday path. Prefer doing it manually? Clone the project and use the bundled scripts.

Manual install
$ git clone https://github.com/Mandrusian/GlassDock.git
$ cd GlassDock
$ ./scripts/install-deps.sh
$ ./install.sh
$ ./scripts/run-tests.sh

What you need

A Wayland session with wlr-layer-shell, Python 3.9+, GTK 3, PyGObject, Pycairo, and gtk-layer-shell. Sway or SwayFX is recommended for Sway IPC integration.

Your settings stay yours. Configuration lives in ~/.config/glassdock/config.json. The installer runs from the project directory you install, and the uninstaller preserves settings unless you explicitly choose to remove them.

🔍 Honest by design

GlassDock is built with Python + GTK 3 + gtk-layer-shell. It does not require GNOME Shell, KDE Plasma, or X11. Some compositor-specific behavior can vary, so validate rendering, layer placement, and blur in your own Wayland session. Check the project README for current requirements, limitations, and troubleshooting notes.
